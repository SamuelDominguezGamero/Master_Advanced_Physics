```bash
mdview file.md
```
y ya deberíamos poder visualizalo en un navegador, sin problemas. Viene muy bien para los .md generados por la IA.

Semana 2: Métodos Estadísticos.

En esta semana se debe estudiar el capítulo 3 del texto base 1 y los capítulos 3 y 4 del texto base 2. En este se estudia la representación de datos, algunos tests de hipótesis y la caracterización de los errores tipo I y II.

Se debe realizar el tutorial de Introducción a los Métodos estadísticos con Matlab:

https://matlabacademy.mathworks.com/es/details/statistics-onramp/orst

Se debe aprender a importar datos con Matlab.

Carga de datos tipo hoja de cálculo, xls, csv, …: https://www.mathworks.com/help/matlab/ref/readtable.html

Lectura de una matriz en un archivo: https://www.mathworks.com/help/matlab/ref/readmatrix.html

Importar data en diversos formatos: https://www.mathworks.com/help/matlab/ref/importdata.html

Estudio Capítulo 3 del texto base.

Debe estudiarse el capítulo 3 del texto base 1 y los capítulos 3 y 4 del texto base 2. El documento que figura a continuación es un "Live Script" indica como realizar en Matlab muchos de los cálculos, análisis y representaciones gráficas indicados en el capítulo y lo complementa con otros. Como es preceptivo en un máster de investigación, el estudiante no debe restringirse a usar las funciones o técnicas utilizadas en el documento, es preciso que investigue por su cuenta para completar sus habilidades. Es por tanto recomendable que el estudiante vaya confeccionando su propio "Live Script" con sus propias notas donde use sobre un conjunto de datos o conjuntos generados artificialmente las diferencies técnicas, representaciones gráficas, etc. El archivo comprimido contiene diferentes conjuntos datos usados en Ciencia de Datos como ejemplos arquetípicos en problemas de regresión, clasificación, etc.

Semana 3: Regresión Lineal.

En esta semana se debe estudiar el Capítulo 6.1 del texto base 1 y los capítulos 5 y 6 del texto base 2. Esta sección versa sobre la regresión lineal de una o múltiples variables que puede extenderse mediante transformación de las variables a regresión polinómica o incluso formas funcionales más complejas.

Se debe realizar el curso de ajuste de curvas de MATLAB

https://matlabacademy.mathworks.com/es/details/curve-fitting-onramp/orcf

Se debe practicar con el software Matlab para aprender a trabajar con el comando de ajuste a diferentes modelos polinómicos y funcionales: https://www.mathworks.com/help/curvefit/fit.html

Se debe practicar con el comando que realiza un análisis de componentes principales para reducir la dimensionalidad: https://www.mathworks.com/help/stats/pca.html

Se debe practicar como obtener las matrices de varianzas-covarianzas y los coeficientes de correlación

https://www.mathworks.com/help/matlab/ref/cov.html

https://www.mathworks.com/help/matlab/ref/corrcoef.html
